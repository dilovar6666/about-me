# DIO — Personal Site

Интерактивный персональный сайт без сборщика и зависимостей.

## Запуск
Открой `index.html` двойным кликом.

Или:
```bash
python -m http.server 8000
```
Затем открой http://localhost:8000

## Файлы
- index.html — структура
- style.css — дизайн, адаптив и анимации
- script.js — интерактив, tilt и переключение темы

Google Fonts используются при наличии интернета; без него сработают fallback-шрифты.
